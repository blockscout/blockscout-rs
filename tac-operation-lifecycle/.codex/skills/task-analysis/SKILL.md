# Task Analysis

Use for feature, enhancement, refactor, or design requests before implementation.

Follow `../../../.memory-bank/workflows/task-analysis.md`.

Read relevant memory-bank context and source-of-truth code before proposing options. Write `task.md`, `solution_N.md`, and `solutions.md` for multiple serious options. Separate facts, assumptions, and recommendations; do not choose between material tradeoffs until evaluation criteria are aligned with the human.
